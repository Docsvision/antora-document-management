//tag::number[]
. В поле _Регистрационный номер_ выделите регистрационный номер для исходящего документа по правилам, настроенным в _Справочнике нумераторов_.
+
Для этого нажмите на кнопку image:6.1@webclient:user:buttons/number.png[Номер] и подтвердите операцию. Если номер добавлен ошибочно, удалите его кнопкой image:6.1@webclient:user:buttons/x-red-circle.png[Крестик].
//end::number[]

//tag::date[]
. В поле _Дата регистрации_ укажите дату регистрации документа. Для этого нажмите на кнопку image:6.1@webclient:user:buttons/calendar-grey.png[Треугольник вниз] и выберите дату из встроенного календаря.
+
По умолчанию в поле будет указана текущая дата.
//end::date[]

//tag::select[]
Для этого нажмите на кнопку image:6.1@webclient:user:buttons/book.png[Книга] и выберите запись из _Справочника сотрудников_. Если запись добавлена ошибочно, удалите её кнопкой image:6.1@webclient:user:buttons/x-red-circle.png[Крестик].
//end::select[]

//tag::tip[]
NOTE: В представление вывод содержания по умолчанию не предусмотрен, но, При необходимости может быть настроен администратором. Также при определённой настройке содержание может учитываться при поиске.
//end::tip[]

//tag::calendar[]
Для этого нажмите на кнопку image:6.1@webclient:user:buttons/calendar-grey.png[Треугольник вниз] и выберите дату из встроенного календаря.
//end::calendar[]

//tag::need-work[]
. Если требуется работа с документом, нажмите в карточке _Документ_ кнопку *Зарегистрировать*. При этом документ переводится в состояние `Зарегистрирован`.
+
.Операции, которые доступны в данном состоянии:
//end::need-work[]

//tag::reg-tab[]
. Найдите область _Информация_.
//end::reg-tab[]

//tag::theme[]
. В поле _Тема_ укажите название документа, которое затем будет отображаться в представлении _Дайджест_ в столбце _Тема_ и в названии исходящего документа. Поле обязательно для заполнения.
//end::theme[]

//tag::prepared[]
. В поле _Подготовил_ укажите сотрудника, который подготовил проект документа.
+
Для этого нажмите на кнопку 6.1@webclient:user:buttons/book.png[Книга] и выберите запись из _Справочника сотрудников_. Если запись добавлена ошибочно, удалите её кнопкой image:6.1@webclient:user:buttons/x-red-circle.png[Крестик].
//end::prepared[]

//tag::content[]
. В поле _Примечание_ укажите произвольное описание документа.
+
Например: `Документ содержит информацию о том, как проводить аттестацию в подразделениях`.
+
NOTE: В представление вывод примечания по умолчанию не предусмотрен, но, при необходимости может быть настроен администратором. Также при определённой настройке содержание может учитываться при поиске.
//end::content[]

//tag::names[]
Фамилии сотрудников, указанные в полях, будут скопированы в используемый по умолчанию режим _расширенного_ согласования _Согласование с подписанием_.
//end::names[]

//tag::start[]
.Чтобы указать сотрудников, которые будут участвовать в согласовании и подписании документа:
. Найдите область _Согласование_.
//end::start[]

//tag::finish[]
. В поле _Подписывает_ укажите фамилии сотрудников, которые будут участвовать в процессе подписания исходящего документа.
+
Для этого нажмите на кнопку image:6.1@webclient:user:buttons/book.png[Книга] и выберите запись из _Справочника сотрудников_.
+
Если запись добавлена ошибочно, удалите её кнопкой image:6.1@webclient:user:buttons/x-red-circle.png[Крестик].
+
. Создайте xref:6.1@webclient:user:docs-approval.adoc[согласование] исходящего документа.
//end::finish[]

//tag::approvers[]

+
Если запись добавлена ошибочно, удалите её кнопкой image:6.1@webclient:user:buttons/x-red-circle.png[Крестик].
//end::approvers[]
