= Создание входящего документа

Для ввода в систему xref:docs-fields-incoming.adoc[входящего] документа выполните следующие действия.

. В папке menu:Документы[01. Входящие] создайте новую карточку _Документ_ одним из способов, описанных в пункте xref:docs-new.adoc[Создание карточки документа].
. Заполните xref:docs-fields-incoming.adoc[поля карточки]:
+
* <<general,Область "Информация">> об организации, в том числе регистрационный номер и получателей документа.
* <<senders,Информацию об организации-отправителе документа>>.
+
. Присоедините к карточке файлы документа, как описано в пункте xref:appendix/files.adoc[Прикрепление файлов].
. Укажите связанные карточки (при их наличии), как описано в пункте xref:appendix/links.adoc#old[Указание связанного документа].

[#general]
== Информация

Информация включает основные атрибуты документа и используется для регистрации документа в системе _{dv}_.

.Чтобы заполнить "Информацию" входящего документа, выполните следующие действия:
. Создайте новую или откройте существующую карточку вида xref:docs-fields-incoming.adoc["Документ УД -- Входящий"].
+
.Заполнение Информации входящего документа
image::incoming-general.png[Заполнение Информации входящего документа]
+
include::partial$excerpts.adoc[tags=theme]
+
Например, может использоваться тема `Регламент проведения аттестации`.
+
Использование поля _Тема_ в представлении и названии карточки настраивается в программе _{kvr}_. Для вида _Входящий_ по умолчанию в представление в виде колонок грида выводятся следующие поля карточки: `Номер + Дата + Тема + Регистратор + Отправитель + Получатель + Состояние + Дата создания + Дата изменения`.
+
include::partial$excerpts.adoc[tags=number]
+
Номер требуется при xref:documents/incoming/register.adoc[регистрации] входящего документа.
+
include::partial$excerpts.adoc[tags=date]
+
. В поле _Получатели_ выберите сотрудников, которым данный документ будет отправлен на ознакомление.
+
include::partial$excerpts.adoc[tags=select]
+
. В поле _Примечание_ укажите произвольное описание документа.
+
Например: `Документ содержит информацию о том, как проводить аттестацию в подразделениях`.
+
include::partial$excerpts.adoc[tags=tip]
+
. Сохраните изменения.

[#senders]
== Отправители входящего документа

Информация об отправителях заполняется для хранения в карточке входящего документа сведений об организации-партнере (контрагенте), от которой поступил данный документ. Информация данных полей носит ознакомительный характер и отображается в _Области представления_.

.Чтобы заполнить информацию об отправителях, выполните следующие действия:
. В карточке вида _Документ УД -- Входящий_ перейдите на вкладку _Регистрация_, в области _Регистрационные данные_ найдите область _Отправители_.
+
.Заполнение сведений об отправителях входящего документа
image::incoming-senders.png[Заполнение сведений об отправителях входящего документа]
+
. В поле _Номер отправителя_, при необходимости укажите номер, который выдали документу в организации контрагента.
. В поле _Дата отправки_ укажите дату регистрации документа на стороне контрагента.
+
include::partial$excerpts.adoc[tags=calendar]
+
Например, если в поступившем документе указано: `Договор №100500 от 13.12.2018`, то в поле следует указать значение `13.12.2018`.
+
. В поле _Отправитель_, при необходимости укажите фамилию ответственного сотрудника организации контрагента.
+
Для этого нажмите на кнопку image:5.5.17@webclient:user:buttons/book.png[Книга] и выберите запись из _Справочника контрагентов_. Если запись добавлена ошибочно, удалите её кнопкой image:5.5.17@webclient:user:buttons/x-red-circle.png[Крестик].
+
При выборе отправителя в поле _Отправитель-контрагент_ из _Справочника контрагентов_ будет автоматически скопировано название организации данного сотрудника.
+
. В поле _Отправитель-контрагент_ укажите название организации, от которой поступил документ.
+
Для этого нажмите на кнопку image:5.5.17@webclient:user:buttons/book.png[Книга] и выберите запись из _Справочника контрагентов_. Если запись добавлена ошибочно, удалите её кнопкой image:5.5.17@webclient:user:buttons/x-red-circle.png[Крестик].
+
. Создайте карточку кнопкой *Создать*.
