= Обработка входящей корреспонденции внутри организации

Обработка входящей корреспонденции является произвольным сценарием в приложении _{dm}_.

.Получатель корреспонденции может выполнить следующие действия:
* xref:6.1@webclient:user:appendix/email-button.adoc[Отправить получателям ссылку на документ по электронной почте].
* xref:6.1@webclient:user:docs-to-acknowledgement.adoc[Отправить документ на ознакомление].
* xref:6.1@webclient:user:tasks-new.adoc[Создать произвольное задание по документу].
* xref:6.1@webclient:user:task-groups-new.adoc[Создать группу заданий по документу].
* Добавление связанных xref:6.1@webclient:user:tasks-related-tasks.adoc[задач] или xref:6.1@webclient:user:tasks-related-docs.adoc[документов].
* xref:6.1@webclient:user:docs-reply-incoming.adoc[Создать исходящий документ в ответ на входящий].

[#cancel]
== Отмена операций с документом

Документ может быть переведен в любое из предыдущих состояний. Для этого служат кнопки на ленте карточки _Документ_, имеющие соответствующие названия:

* *Вернуть на подготовку* -- для _Автора_ в зарегистрированном документе.
* *Вернуть в Зарегистрирован* -- для _Исполнителя_ в документе, находящемся в работе и т. д.

Операция может выполняться с документом, находящимся в состоянии `Зарегистрирован`, `В работе`, `В Архиве`.
