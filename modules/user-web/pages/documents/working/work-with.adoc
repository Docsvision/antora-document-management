= Рабочая документация

Для рабочей документации используются вид карточки xref:5.5.17@webclient:user:docs-fields-working.adoc[Рабочий].

.Основной сценарий работы с данной документацией включает выполнение следующих операций:
. xref:documents/working/create.adoc[Ввод документа в систему, подготовка файла документа].
. Согласование документа:
+
.. Отправка документа на согласование.
.. Получение заданий на согласование.
. xref:documents/working/take.adoc[Назначение документа действующим].
. xref:documents/working/operations.adoc[Организация работ по документу].
