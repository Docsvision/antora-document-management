= Организация работ по рабочему документу

Выполнение операций с рабочим документом является произвольным сценарием в приложении _{dm}_. При подготовке документов могут быть выполнены следующие действия:

* xref:6.1@webclient:user:appendix/email-button.adoc[Отправка получателям ссылки на документ по электронной почте].
* xref:6.1@webclient:user:docs-to-acknowledgement.adoc[Отправка документа на ознакомление].
* xref:6.1@webclient:user:tasks-new.adoc[Создание произвольного задания по документу].
* xref:6.1@webclient:user:task-groups-new.adoc[Создание группы заданий по документу].
* Добавление связанных xref:6.1@webclient:user:tasks-related-tasks.adoc[задач] или xref:6.1@webclient:user:tasks-related-docs.adoc[документов].
* xref:6.1@webclient:user:tasks-user-performer.adoc[Получение документа и исполнение заданий по документу].
