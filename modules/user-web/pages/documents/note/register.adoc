= Регистрация служебной записки

Регистрация служебной записки может производиться до или после согласования и подписания документа. Обязательными для заполнения при регистрации являются поля _Тема_ и _Регистрационный номер_.

Карточка регистрируемого документа должна быть в состоянии `Подготовка`, `Согласован` или `Подписан`.

* Возврат документа на подготовку.
* Наложение электронной подписи.
* Просмотр журнала подписей.
