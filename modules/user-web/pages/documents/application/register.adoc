= Регистрация заявки

Регистрация может производиться до или после согласования и подписания заявки документа. Обязательными для заполнения при регистрации являются поля _Тема_ и _Регистрационный номер_.

Карточка регистрируемого документа должна быть в состоянии `Подготовка`, `Согласован` или `Подписан`.
