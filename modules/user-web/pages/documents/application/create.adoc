= Создание заявки

.Заявка может быть создана несколькими способами:
* Как отдельный самостоятельный документ, не связанный с другими карточками.
* Как связанный с любым из ранее созданных в системе документом. Подробнее процесс описан в пункте "xref:links.adoc#old[Создание связанного документа]".

.Для создания проекта заявки:
. В папке menu:Документы[04. Заявки] создайте новую карточку вида _Заявка_ одним из способов, описанных в пункте xref:docs-new.adoc[Создание карточки документа].
. Заполните атрибуты карточки, расположенные на вкладке _Регистрация_ в области _Регистрационные данные_:
+
* Укажите общую информацию об организации, в том числе регистрационный номер.
* Выберите участников согласования по документу.
* Выберите получателей документа.
+
. При необходимости прикрепите к карточке файл(ы) документа, как описано в пункте xref:files.adoc[Прикрепление файлов].
. Укажите связанные карточки (при их наличии), как описано в пункте xref:links.adoc#old[Указание связанного документа].
. Сохраните выполненные изменения, нажав кнопку *Сохранить* в созданной карточке _Документ_.
