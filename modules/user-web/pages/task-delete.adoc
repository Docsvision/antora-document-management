= Удаление задания

Карточка _Задание_ может быть удалена пользователем при выполнении следующих условий:

* Карточка задания разблокирована.
* Карточка в состоянии `Подготовка` или `Отозвано`.
* Пользователь должен обладать достаточными правами на удаление карточки.

См. общую инструкцию по удалению в пункте xref:6.1_GBL-3828@webclient:user:cards-delete.adoc[Удаление карточки]. При удалении задания ссылки на него будут удалены из других карточек.
